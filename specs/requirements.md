## 1. 产品概述

### 1.1 产品定位

DevToolBox 是一款面向 Web 开发者的**浏览器端多功能工具集**。用户无需安装、无需注册、打开即用。所有数据处理在用户本地浏览器中完成，不涉及后端服务器。

### 1.2 目标用户

| 角色 | 典型场景 | 需求重点 |
|------|----------|----------|
| 前端开发者 | 调试 JSON 数据、格式化代码 | JSON 编辑、YAML 转换 |
| 全栈开发者 | 接口调试、数据交换 | 格式化、校验、可视化查看 |
| SaaSSY 用户 | 批量下载学习教程 | 配置生成 → Python 脚本 → 批量下载 → 合成为 PDF |
| 文档工作者 | 将 HTML 转为 PDF | HTML 编辑、实时预览、PDF 导出 |

### 1.3 核心原则

| 原则 | 说明 |
|------|------|
| **零依赖** | 无需后端、无需数据库、无需注册登录 |
| **纯本地** | 数据不出浏览器，不上传服务器 |
| **响应式** | 支持桌面和移动端浏览器 |
| **离线可用** | 首次加载后，核心工具可离线运行 |
| **暗色模式** | 全站亮/暗双模式，跟随系统或手动切换 |

## 3. 非功能需求

### 3.1 性能

| 需求 ID | 描述 | 指标 | 优先级 |
|---------|------|------|--------|
| NF-001 | JSON 编辑器处理 5MB 以内文件，格式化/验证响应时间 ≤ 2s | 5MB 文件 | P0 |
| NF-002 | YAML/JSON 实时转换防抖 500ms，避免高频转换卡顿 | 防抖 500ms | P0 |

| NF-004 | JSON 树状视图：万级节点的展开/折叠无明显卡顿 | 10,000 节点 | P2 |

### 3.2 兼容性

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| NF-005 | 支持 Chrome ≥ 90、Edge ≥ 90、Firefox ≥ 90、Safari ≥ 15 | P0 |

| NF-007 | Tailwind CSS `dark:class` 模式，非 `prefers-color-scheme` | P0 |

### 3.3 安全

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| NF-008 | **禁止 `v-html` 渲染未净化的用户输入** | **P0 红线** |
| NF-009 | 用户输入的 Cookie/token 仅限于存储在内存或 localStorage，不上传任何服务器 | P0 |

| NF-011 | 剪贴板复制必须使用 `navigator.clipboard.writeText()` | P0 |

### 3.4 可用性

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| NF-012 | 所有 icon 按钮必须有 `title` 属性或 `aria-label` | P1 |

## 5. 数据流架构

### 5.1 数据流向

```
用户操作 → Vue 组件(emit) → Pinia Store → 状态更新 → 响应式视图渲染
                                       ↓
                                  (可选) localStorage 持久化
                                       ↓
                                  (可选) 文件下载/剪贴板
```

### 5.2 存储策略

| 数据 | 存储方式 | 生命周期 |
|------|----------|----------|
| 主题偏好 | localStorage | 永久 |
| 侧边栏状态 | localStorage | 永久 |
| 编辑器内容 | ref (内存) | 会话级 |
| 认证 Cookie/Token | ref (内存) | 会话级（刷新即失） |

## 7. 红线条款（违反即为需求不通过）

1. **HTML 转 PDF** 不得调用 `window.print()`，须使用真正的 PDF 生成方案
2. 不得将用户输入的 Cookie 或 Token 发送到任何外部服务器
3. 所有 `JSON.parse` / `js-yaml.load` 必须包 try/catch
4. 组件卸载时必须清除所有 `document.addEventListener` 残留
5. Monaco Editor 主题必须随全局暗色模式自动切换
6. 不可在模板中使用 `v-html` 渲染未经净化的数据
